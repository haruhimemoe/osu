# Security

Please report vulnerabilities in this package privately instead of opening an issue:

1. **GitHub:** [report a vulnerability](https://github.com/haruhimemoe/osu/security/advisories/new) (private vulnerability reporting).
2. **Email:** haruhime@haruhime.moe, if you can't use GitHub.

Include steps to reproduce and the impact you expect. You'll get a reply within 7 days.
